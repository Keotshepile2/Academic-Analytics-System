How the Model Works

The system uses a Logistic Regression classifier trained on historical student data. It analyses features like average marks, failed modules, GPA, and declining trends to compute a risk probability for each student. Higher probabilities indicate higher risk.

Note: This is a decision-support tool. Predictions are based on synthetic data and should be interpreted by academic advisors using professional judgement.
